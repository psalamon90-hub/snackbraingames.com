# snackbraingames.com

Static website of Snackbrain Games, served by GitHub Pages on the custom domain snackbraingames.com.

- `index.html`: studio home page with all games (Arrowtopia, Donut Spin, Paws Apart), English and Polish, switch in the top bar.
- `assets/`: game icons and screenshots; each game card uses its own game's colours and pictures, the studio frame stays plain.
- `privacy.html`: privacy policy for the games (Arrowtopia, Donut Spin; Android and iPhone) and the website (English and Polish). Add each new game to the list in section 2 before it goes live. URL for Google Play: https://snackbraingames.com/privacy.html
- `app-ads.txt`: add the AdMob publisher line once the AdMob account exists.
- `CNAME`: custom domain for GitHub Pages.
- No cookies, no analytics, no third-party scripts. Font Barlow (SIL Open Font License) is self-hosted in `fonts/`.
