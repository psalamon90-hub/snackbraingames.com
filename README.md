# snackbraingames.com

Static website of Snackbrain Games, served by GitHub Pages on the custom domain snackbraingames.com.

- `index.html`: studio home page (English and Polish, switch in the top bar).
- `privacy.html`: privacy policy for Arrowtopia: Arrow Puzzle and the website (English and Polish). URL for Google Play: https://snackbraingames.com/privacy.html
- `app-ads.txt`: add the AdMob publisher line once the AdMob account exists.
- `CNAME`: custom domain for GitHub Pages.
- No cookies, no analytics, no third-party scripts. Fonts (Fredoka, Nunito, SIL Open Font License) are self-hosted in `fonts/`.
